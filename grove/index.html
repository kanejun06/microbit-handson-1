⚡ はじめる前に

どの課題も、進め方は同じです。

  • つなぐ：配線図のとおりに、モジュールをシールドのポートへ。micro:bit はシールドに差し込みます。
  • 組む：MakeCode で、画像と同じブロックを組んで micro:bit にダウンロード。
  • 試す：動いたら「やってみよう」で数字やブロックを変えて、動きの違いを確かめる。

モジュールを2つ以上つなぐ課題は電力を多く使います。動きが不安定なときは、シールド側のUSBポートにケーブルをつないで給電してください。

プログラムをざっと解説

ここからは、音声ファイル（mp3 / wav）を再生できるモジュールを使います。ブザーの音やメロディではなく、自分で用意した音（効果音・声・音楽）を鳴らせます。

SAMPLEmp3playerVer4 の使い方

音声ファイルを鳴らすための基本モジュールを動かします。共有プロジェクトを開いて中身を確認しましょう。

▶MakeCode: mp3playerVer4
ポイント：このモジュールは mp3 と wav のどちらも再生できます。音声ファイルは 0001.mp3、0002.mp3…（wav なら 0001.wav、0002.wav…）のように連番のファイル名で microSD に入れておきます。この番号が、プログラムから「1番の音」「2番の音」と呼び出すときの番号になります。ファイル名は拡張子の前が8文字までです。

サンプル音源

鳴らす音をまだ用意していない人は、打楽器のサンプル音源をここからダウンロードして使えます。中身は wav ファイルです。

⬇打楽器サンプル音源（DrumSamples.zip）
  1. zip を展開して、使いたい音を選ぶ
  2. ファイル名を 0001.wav、0002.wav… のように連番に付け直して、microSD に入れる
  3. プログラムの配列に入っているファイル名も、0001.mp3 → 0001.wav のように拡張子を書き換える
⚠ 拡張子まで一致させる
microSD のファイル名と、プログラムに書いたファイル名は、拡張子（.mp3 / .wav）まで同じにします。ここが違うと音が鳴りません。
⚠ 注意：電池ボックスを必ず接続！
mp3player を使うときは、単四電池3本が入る電池ボックスを micro:bit に接続しないと音が鳴りません！電池ボックスのスライドスイッチが「ON」になっていることも併せて確認してください。

プログラムをざっと解説

まず mp3player を P0 に接続します。このマイコンは 「ATコマンド」 という命令文を受け付けるので、ATコマンドを送って 曲の再生・音量変更・停止 などを行う関数（play / volume / stop）をあらかじめ用意しておきます。

サンプルでは、配列に 0001.mp3 〜 0008.mp3 の8つのファイル名を保持しておき、Aボタンを押すとその中からランダムに1つ選んで再生します。microSD に入れた連番ファイルが、ここで呼び出されるわけです。

wav ファイルを鳴らすときは、この配列の中身を 0001.wav 〜 のように書き換えます。
